> [!WARNING]

> ### АНТИВИРУСЫ
> Антивирус может среагировать на WinDivert.  
> Для работы zapret нужен WinDivert — инструмент, перехватывающий и фильтрующий сетевой трафик.
> Его используют и безопасные, и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Цитата из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы считают файлы WinDivert инструментами повышенного риска или хакерскими утилитами. В результате файл удаляется и попадает в карантин. Такое обнаружение обычно обозначается как `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте папку с zapret в исключения антивируса или отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky для этого есть параметр «Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда». При уверенной настройке исключений предпочтительно добавить исключение; если вы не вполне понимаете, как это сделать, лучше отключить обнаружение PUA.

## ⚙️ Использование

1. Включите безопасный DNS (Secure DNS).
    * В Chrome найдите настройку «Использовать безопасный DNS» и укажите поставщика, отличный от «Поставщик по умолчанию».
    * В Firefox откройте «DNS через HTTPS», выберите режим «Персональный», затем «Выбрать провайдера/поставщика» и вручную введите его URL. Например: `https://dns.google/dns-query`. Поставщик Cloudflare может быть заблокирован.
    * В Windows 11 Secure DNS можно активировать непосредственно в параметрах системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Этот вариант рекомендуется для пользователей Windows 11.
    * На роутере Keenetic включите параметр «Транзит запросов». Если он отключён, настройка и работа Secure DNS на компьютере могут быть нарушены.

2. Загрузите ZIP- или RAR-архив с [последнего релиза](https://github.com/cresthelperenhance12/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и отметьте «Разблокировать». Для архиваторов 7-Zip и PeaZip этот шаг не требуется.

4. Распакуйте архив в каталог, путь к которому не содержит кириллицы или специальных символов.

5. Запустите подходящий файл.
    * Чтобы подобрать работающую стратегию, откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
    * Для автоматического запуска выберите **`service.bat`** → `Install Service` → нужную стратегию.

## ℹ️ Кратко о файлах

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Ручной запуск удобен для проверки стратегий: их результат зависит от множества условий. **Переберите разные варианты (ALT, FAKE и другие), пока не найдёте подходящий для себя.**

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск служб Windows (services.msc).</ins>
  - **`Remove Services`** — убрать стратегию и WinDivert из служб.
  - **`Check Status`** — посмотреть состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** — включить или отключить обход для игр и других служб, использующих UDP и TCP на портах выше 1023.  
  После смены режима стратегию нужно перезапустить.  
  В скобках показано текущее состояние: включено или выключено.
  - **`IPSet Filter`** — переключить обработку ресурсов из `ipset-all.txt`. Это пригодится при проверке ресурса, который доступен без zapret, но не работает с ним.  
  В скобках отображается режим:
    - `none` — IP-адреса не проверяются.
    - `loaded` — адреса сверяются со списком.
    - `any` — фильтр применяется к любому IP.
  - **`Auto-Update Check`** — включить или отключить автоматическую проверку обновлений.
  - **`Replace active fakes`** — сменить используемый фейк на другой из каталога `bin`.
  - **`Update IPSet List`** — загрузить актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**.</ins>
  - **`Check for Updates`** — проверить наличие обновлений.
  - **`Run Diagnostics`** — найти распространённые причины сбоев zapret. В конце можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это может помочь, если он внезапно перестал работать.
  - **`Run Tests`** — запустить проверку стратегий:
    - `Standard tests` — протестировать сайты из `utils/targets.txt`.
    - `DPI checkers` — проверить DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и неполадки

### После запуска `general*` ничего не происходит

При запуске стратегии отдельным BAT-файлом, а не через service, должен появиться `winws.exe` — процесс обхода, видимый на панели задач.  
Если его нет, ознакомьтесь с [#522](https://github.com/cresthelperenhance12/zapret-discord-youtube/issues/522).

### Не удалось подобрать стратегию

- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезагрузите компьютер.

### Веб-версия Telegram не подключается
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося Блокнота.
  - Через текстовый редактор, запущенный от администратора, откройте `hosts` в созданной папке.
  - Вставьте скопированное в конец `hosts` либо замените ранее добавленные аналогичные записи.
  - Сохраните файл и проверьте подключение. Если проблема осталась, проверьте, что изменения действительно сохранены.

#### Результат не гарантирован. Если этот способ не сработал, используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/cresthelperenhance12/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Со временем стратегия может перестать работать.**
> Обнаружение стратегии может привести к тому, что ранее рабочий вариант перестанет обходить блокировку.
> В репозитории есть разные стратегии. Если ни одна не подходит, создайте новую на основе имеющейся и измените её параметры.
> О параметрах стратегий рассказано [в документации](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что `service.bat` → `Run Diagnostics` не показывает ошибок.
- Проверьте, добавлен ли адрес нужного ресурса в список доменов или IP.
- Испытайте другие варианты, например **`ALT`** или **`FAKE`**.
- При необходимости выполните полную переустановку по инструкции ниже.
- Дополнительная информация: [#765](https://github.com/cresthelperenhance12/zapret-discord-youtube/issues/765).

### Полная переустановка или обновление

- Сохраните добавленные вами ресурсы и данные.
- Перезапустите устройство.
- Выполните `service.bat` → `Remove Services`.
- Запустите `service.bat` → `Run Diagnostics`; устраните найденные ошибки, а в конце введите Y.
- Удалите каталог zapret.
- Скачайте свежую версию (`zapret-discord-youtube-...`) со [страницы релизов](https://github.com/cresthelperenhance12/zapret-discord-youtube/releases).
- Щёлкните по архиву правой кнопкой, откройте свойства и, если доступен флажок «Разблокировать» внизу справа, отметьте его. Нажмите «Применить», затем «ОК».
- Распакуйте архив в новый каталог в корне диска; в пути не должно быть пробелов и специальных символов.
- Запускайте разные скрипты `general` и проверяйте доступ к ресурсам. Если они недоступны, закройте программу через значок замка на панели задач и запустите другую стратегию.
- Найдя рабочий вариант, добавьте его в автозапуск: `service.bat` → `Install Service` → выберите стратегию.

### Игра или приложение не работает при включённом zapret

Проверьте в `service.bat`, что `Game Filter` установлен в **`disabled`**, а `IPSet Filter` — в **`none`**. Другие значения могут повлиять на доступность ресурсов, с которыми вы не планировали работать.

### Античит сообщает о WinDivert

Инструкция доступна [здесь](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

### Windows 7 требует цифровую подпись драйвера WinDivert

Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё числится в службах

1. В командной строке Windows (Win+R, затем `cmd`) получите имя службы:

```cmd
driverquery | find "Divert"
```

2. Остановите её и удалите:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS настроен](#%EF%B8%8F-использование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если раньше всё работало, поочерёдно проверьте остальные стратегии.
- См. также обсуждение [#251](https://github.com/cresthelperenhance12/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS включён](#%EF%B8%8F-использование).
- Сначала выясните, какая стратегия открывает сайт YouTube, и запустите её.
- В `service.bat` выберите `Run Diagnostics` и очистите кэш Discord.
- Проверьте, заработало ли приложение после очистки.
- Откройте Discord в браузере по адресу https://discord.com/app. Если там он работает, можно пользоваться веб-версией.
- Если браузерная версия тоже недоступна, снова переберите стратегии: YouTube и Discord могут работать на разных вариантах.
- Дополнительное обсуждение: [#252](https://github.com/cresthelperenhance12/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/cresthelperenhance12/tg-ws-proxy).
- Также можно подключиться через бесплатные MTProto-прокси из интернета.

### Игры не подключаются

Игр много, поэтому проверить и устранить неполадки в каждой из них невозможно.

Для начала попробуйте следующее:
- Обновите ipset через `service.bat` и включите `Game Filter`.
- Если это не помогло, включите также `ipset any`.

Учтите: режим `ipset any` может помешать открытию многих сайтов. Не оставляйте его включённым постоянно. Вместо этого выясните все IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`.

Если игра всё ещё не работает, откройте обсуждение в разделе [Discussions](https://github.com/cresthelperenhance12/zapret-discord-youtube/discussions), а не в issues, и дождитесь ответа других игроков.

### Не нашли подходящего ответа

Опишите проблему [здесь](https://github.com/cresthelperenhance12/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов других ресурсов

Дополнить списки для обхода можно в следующих файлах:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда IP-сеть есть в `ipset-all.txt`, но отдельный домен фильтровать не следует.
- **`ipset-all.txt`** — IP-адреса и подсети.
- **`ipset-exclude-user.txt`** — IP-адреса и подсети для исключения.
  - Файлы **`*-user.txt`** появятся автоматически при первом запуске `zapret` или `service.bat`.
